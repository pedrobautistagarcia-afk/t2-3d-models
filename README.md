# T2 · Roof in 3D

Offline 3D model of the Kuwait International Airport Terminal 2 roof (L400), built from the L400 Roof Plan drawing.

Open `index.html` in Chrome or Safari (double-click). No internet needed; keep all files in the same folder.

To test editing: change the name in `index.html` (line marked EDIT HERE) and commit. The page shows it under "Edited by".
